# Caustic Studio

一个从零实现的实时渐进路径追踪器。场景包含黄铜金属球、悬浮玻璃球、漫反射地面和面光源，重点演示 BVH 求交、反射 / 折射、面积光软阴影、玻璃焦散、渐进累积、相机重投影以及可恢复的采样快照。

全部渲染算法在 GLSL 中自行实现，不依赖 Three.js 或任何渲染库；项目没有运行时外部依赖。

## 运行

需要支持 WebGL2 与 `EXT_color_buffer_float` 的浏览器，推荐 Chrome / Edge。

```bash
node serve.mjs
```

或直接双击 `run.bat`。随后打开：

```
http://127.0.0.1:8123/
```

也可以在已有 Node 环境里使用 `npm start` 或 `pnpm start`。项目通过本地静态服务器运行，因为浏览器不允许从 `file://` 加载 ES 模块和持久化数据。

## 渲染实现

### 场景与 BVH

- 图元同时支持球体与四边形；地面和面光源是四边形，两个球是解析球体。
- `src/bvh.js` 在 CPU 上按质心最长轴中位数分裂构建 BVH，节点和索引展平后作为 uniform 数组上传。
- `src/shaders/trace.js` 中实现 AABB slab 测试、BVH 栈式遍历、球体二次方程求交和四边形平面求交。
- 面光源的采样点与可见性检测复用同一套 BVH 求交。

### 材质与光照

- 漫反射地面：Lambertian，余弦权重采样，并做单点面积光 NEE。
- 金属球：GGX 半程向量采样 + 粗糙度控制 + Schlick 菲涅尔边缘反射。直接光源反射由路径采样完成。
- 玻璃球：电介质菲涅尔分支，支持进入 / 离开界面、全反射、折射率控制与透射颜色。光线穿过玻璃后命中光源时贡献发射，因此会产生真实路径追踪焦散。
- 面光源：均匀面积采样，计算 `cosSurface * cosLight * area / distance²`，提供软阴影。
- 环境：解析式低强度棚拍渐变，只在光线逃逸时加入，不参与 NEE，避免重复计入。
- 最大弹射次数可调（3–12），默认 6；光源为单面发光，光源采样和发光命中使用同一方向约定。

### 累积与相机重投影

- 渲染目标使用两张 `RGBA32F` 纹理 ping-pong：一张存 `RGB 平均值 + alpha 样本数`，一张存主射线命中点的世界坐标。
- 每个像素每帧增加 `N` 个样本，使用硬件浮点平均，因此画面会随采样数增加逐步收敛。
- 相机移动时不会清空累积。新像素会根据主射线命中位置反投影到上一帧相机，并比较上一帧位置缓冲，验证成功的历史颜色和样本数会按权重保留。
- 重投影后进入 20 帧的 settle 阶段，历史样本权重逐帧衰减（0.88），新样本逐步替换旧视角结果；达成渐进更新而不是清零或永久残影。
- 拖拽 / 滚轮期间自动降到 1 spp / 帧以保持交互响应，停止后恢复设定的采样数。
- 采样暂停只停止路径追踪，保留当前累积，恢复后从当前样本数继续。

### 持久化

- 场景、相机、材质、锁定状态和渲染参数保存在 `localStorage`。
- 累积缓冲、主射线位置缓冲、样本数、帧种子和相机在 `IndexedDB` 中保存为快照。
- 每约 8 秒自动保存一次，暂停、页面隐藏和关闭前也会尝试保存；顶栏「保存」可手动立即写入。
- 快照与 `sceneSignature` 绑定，签名包含材质参数、最大弹射次数和分辨率。材质或分辨率变化会使旧累积自动失效。
- 打开页面时，如果签名与分辨率匹配，会恢复累积纹理并继续追加样本。恢复的相机以快照中对应最后一次累积的相机为准，保证画面与样本一致。
- 锁定材质状态不参与渲染签名，但会随场景状态一起持久化，因此刷新后仍然保留。

## 项目结构

```
index.html                 页面结构
styles.css                 视觉系统（8pt 间距、字阶、颜色、控件）
favicon.svg
serve.mjs                  零依赖本地静态服务器
run.bat                    Windows 启动脚本
src/
  main.js                  启动、状态、相机交互、自动保存、恢复
  renderer.js              WebGL2 纹理 / FBO / uniform / ping-pong / 快照读写
  scene.js                 场景、材质、相机、颜色空间与签名
  bvh.js                   CPU BVH 构建
  ui.js                    控制面板、HUD、锁定与重置
  storage.js               IndexedDB 快照存取
  icons.js                 统一线性 SVG 图标
  shaders/
    common.js               全屏顶点着色器 + ACES 显示合成
    trace.js                路径追踪、BVH、材质、NEE、重投影
```

## 已知边界

- 金属采用近似 GGX 方向采样而非完整 microfacet MIS；视觉上支持粗糙反射与菲涅尔边缘，但不是工业级能量守恒实现。
- 焦散由相机路径穿过玻璃后连接到光源产生，属于简单路径追踪焦散；没有光子映射或焦散专用采样，低采样时仍有明显噪声。
- 当前仅支持一个面光源、球体与四边形；BVH 容量预留为 8 个图元 / 16 个节点。
- 没有降噪器。画面靠累积收敛是设计目标。
- 自动保存需要读取浮点缓冲，在低端 GPU 上会短暂造成一次 GPU 同步停顿。若出现卡顿，可增加保存间隔或仅使用暂停 / 手动保存。
